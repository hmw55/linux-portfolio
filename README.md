# Linux Portfolio

A Linux-inspired web portfolio built with React and TypeScript, designed as a desktop-style iinterface to showcase projects and applications

## Goals
- Desktop-style UI inspired by Linux environments
- Modular, app-based architecture
- Clean, readable, and scalable code
- Progressive enhancement overtime

## Tech Stack (Planned)
- React
- TypeScript
- Vite
- GitHub Pages (initial hosting)
